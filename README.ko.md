# Codex Relay

[English](README.md) · [한국어](README.ko.md)

Windows용 경량 Codex 계정 관리 및 사용량 오버레이입니다.

![메인 화면](assets/screenshot.png)

가상 계정으로 구성한 예시 화면입니다. 앱 UI는 현재 한국어로 제공됩니다.

## 주요 기능

- 로그인 링크로 계정 추가 및 전환 순서 설정
- 5시간·주간 한도 표시와 한도 소진 시 다음 계정 전환
- 사용 가능한 계정별로 한도 구간마다 한 번 요청하는 자동 웜업
- 남은 한도·세션 평균 TPS 오버레이, 다크 모드, 투명도 조절
- Windows 시작 시 실행 및 EXE 이동 후 등록 경로 갱신

## 시작하기

Windows 10/11 x64와 .NET Framework 4.8이 필요합니다. 설치와 관리자 권한은 필요하지 않습니다.

1. [Releases](https://github.com/oiloilo44/codex-relay/releases)에서 `CodexRelay.exe`를 내려받습니다.
2. `CodexRelay.exe`를 실행합니다. 최초 실행 시 Codex 로그인 정보가 있으면 현재 계정을 자동으로 저장합니다.
3. 다른 계정은 **계정 추가**에서 로그인합니다. **↑ / ↓**로 전환 순서를 정할 수 있습니다.
4. 필요한 옵션을 켭니다. 자동 전환·웜업·시작프로그램 등록은 기본 OFF입니다.

다크 모드는 기본 ON이며 이후 선택을 저장합니다. 오버레이는 앱을 새로 실행할 때마다 켜지고, 최초에는 화면 우측 하단에 나타납니다. 드래그한 위치와 투명도는 저장하며, 더블클릭하면 관리 창이 열립니다.

오버레이가 켜져 있으면 1초 간격으로 실제 창 순서를 확인하고, 일반 프로그램 뒤에 가려졌을 때 위치·투명도·키보드 포커스를 유지한 채 위로 복구합니다. 오버레이를 끄면 이 확인도 중단합니다.

창의 **X**는 트레이로 숨깁니다. 완전히 종료하려면 **⋯ → 종료**를 선택합니다. **⋯ → Windows 시작 시 실행**으로 자동 실행을 등록·해제할 수 있습니다. EXE를 옮겼다면 기존 Relay를 종료한 뒤 새 위치에서 한 번 실행하세요.

## 동작 안내

- 자동 전환은 목록 순서대로 순환하며, 사용 가능한 계정이 없으면 현재 계정을 유지합니다. 자동 전환을 거절하면 이 옵션을 끄고, 사용자가 다시 켤 때까지 묻지 않습니다.
- 수동 전환은 한도가 소진됐거나 조회되지 않는 계정도 선택할 수 있어 크레딧을 사용할 계정으로 옮길 수 있습니다. 이 경우 선택한 계정을 유지하도록 자동 전환을 끕니다. 현재 계정은 10초, 남은 한도가 5% 이하이면 5초, 다른 계정은 90초 간격으로 조회합니다. 네트워크와 서버 응답에 따라 더 늦어질 수 있습니다.
- 인증이 거부된 계정은 **재로그인 필요**로 표시합니다. 계정 메뉴의 **다시 로그인**으로 인증 정보를 갱신하며, 별칭과 목록 순서는 유지합니다. 다시 로그인할 때까지 자동 조회·전환 대상에서 제외합니다.
- Codex가 실행 중이면 종료·전환 승인이 필요하고 진행 중인 작업이 중단될 수 있습니다. 앱의 정상 종료 명령(`Ctrl+Q`)을 요청하고 최대 60초 기다리며, 종료가 확인되면 즉시 전환·재실행합니다. 시간 초과 후 남은 프로세스의 강제 종료는 별도로 승인해야 하며, 거절하면 현재 인증 정보를 유지합니다. 종료 단축키를 변경했다면 Codex를 직접 종료한 뒤 전환하세요.
- 종료 대상은 버전이 없는 Windows 패키지 ID와 창의 기능 구조로 식별합니다. 메뉴가 감지되지 않으면 같은 주 창을 최대 4회 확인합니다. 메뉴가 계속 숨겨져 있으면 작업표시줄 창 여부, 크기 조절 및 최소화·최대화 기능을 함께 확인합니다. 도구 창과 모달 창은 제외하며, 확인 중 창·프로세스가 바뀌거나 후보가 모호하면 중단합니다. 입력 직전에도 같은 프로세스·창인지 다시 확인합니다.
- 종료 중인 프로세스의 정보 조회가 실패하면 보관한 프로세스 핸들로 실제 종료를 확인합니다. 종료가 확인된 프로세스만 제외하며, 실행 중인데 조회할 수 없는 경우에는 인증을 유지하고 중단합니다. 조회 실패 단계와 PID·Windows 오류 번호는 전환 로그에 기록합니다.
- 자동 웜업은 실제 모델 요청이므로 소량의 사용량을 소비합니다. 한도 조회 자체는 모델 요청을 보내지 않습니다.
- TPS는 실행 중인 로컬 Codex Desktop 세션의 로그를 이용한 턴 평균입니다. 앱 종료·재시작으로 끊긴 세션은 중단 수로 별도 표시하고, 재개하기 전까지 TPS에서 제외합니다. 도구 실행·대기 시간을 포함하며 순간 생성 속도가 아닙니다. 원격·클라우드·별도 CLI 세션은 제외합니다.
- ChatGPT 로그인 정보가 `auth.json`에 저장되는 환경을 지원합니다. API 키 계정과 keyring 저장 방식은 지원하지 않습니다.
- 이 앱은 OpenAI 공식 제품이 아닙니다. Codex의 인증·로그 형식이나 백엔드 변경에 영향을 받을 수 있으며, 배포 EXE에는 코드 서명이 없습니다.

## 데이터 저장

계정 인증 토큰과 설정은 `%LOCALAPPDATA%\CodexRelay\vault.bin`에 Windows DPAPI의 현재 사용자 기준으로 암호화해 저장합니다. 직전 저장본은 `vault.bin.bak`에 보관합니다.

현재 Codex 인증 파일은 기본적으로 `%USERPROFILE%\.codex\auth.json`이며, `CODEX_HOME`을 설정한 경우 해당 경로를 사용합니다. 계정 전환 시 이 파일을 교체합니다. 인증 파일과 보관함은 공유하지 마세요.

시작프로그램은 현재 사용자의 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 아래 `CodexRelay` 값으로 등록합니다.

전환 진단 기록은 `%LOCALAPPDATA%\CodexRelay\logs`에 저장합니다. 종료 입력·창 상태·프로세스 종료 확인을 기록하며 계정 토큰이나 대화 내용은 기록하지 않습니다. **⋯ → 전환 로그 열기**로 폴더를 열 수 있습니다.

## 빌드

Windows PowerShell에서 실행합니다. NuGet이나 별도 .NET SDK 설치는 필요하지 않습니다.

```powershell
.\build.ps1
.\bin\CodexRelay.Tests.exe
```

실행 파일은 `bin\CodexRelay.exe`에 생성됩니다. 기본 테스트는 가상 데이터를 사용하며 실제 계정을 사용하지 않습니다. 화면 검사는 `CodexRelay.Tests.exe --render-hidden`으로 실행할 수 있습니다.

`CodexRelay.Tests.exe --window-readonly`는 실행 중인 Codex의 주 창 선택을 검증합니다. 키 입력·포커스 변경·프로세스 종료·계정 전환 없이 창 정보만 읽습니다.

`CodexRelay.Tests.exe --overlay-window-check`는 가상 데이터로 작은 테스트 창을 잠시 표시해 오버레이의 자동 복구·포커스 유지·숨김 상태를 검증합니다. 실제 계정이나 네트워크를 사용하지 않습니다.
